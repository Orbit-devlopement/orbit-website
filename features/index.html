Developer integrations

Know what’s happening across GitHub and GitLab.

ORBIT puts read-only repository information beside the tasks you’re already tracking. During the private pilot, users connect individually scoped access tokens.

⑂

GitHub repositories

View repositories accessible to your token and inspect issues, open pull requests, and workflow status. Organization approval may be necessary for private repos.

⎇

GitLab projects

Browse GitLab.com projects, open merge requests, issues, and pipelines with a scoped read_api token.

▦

Personal task tracking

Use your Kanban board to track external work. Tracking an issue does not change it in GitHub or GitLab.

Pilot boundaries

Designed to see clearly, not overreach.

ORBIT deliberately limits the repository connector to read operations and known provider API endpoints. Repository code content is not currently analyzed by these connections.

Security details

Only GitHub.com and GitLab.com are supported in the per-user connector beta.

Token management is manual. Self-serve OAuth and refresh flows are not available yet.

Results currently use bounded first-page lists rather than exhaustive pagination.

Use fine-grained GitHub permissions or GitLab read_api for the least necessary access.
