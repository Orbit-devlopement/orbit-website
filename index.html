Repository connections fetch data through a server function; ORBIT does not automatically push commits or merge requests.

Read our security approach ↗

Repository data is read through provider API calls; the connector does not request write operations.

Connection credentials are designed for server-side encrypted storage, not browser local storage.

Access to private workspaces is gated by login, approval, and multi-factor authentication in the pilot.

AI agent execution is separate from ordinary account access and requires manual approval.

Questions

Everything you need to know.

Is ORBIT available to everyone?

Not yet. ORBIT is an invite-only beta. We are validating integrations and security before accepting general signups.

Can ORBIT read my private GitHub and GitLab repositories?

Yes, when your provider grants the necessary read permissions. During the beta, each user supplies a scoped access token for their selected account.

Can ORBIT commit, merge, or deploy changes automatically?

No. The repository connectors are read-only. Trusted operators may configure a separate approval-gated local agent worker; it is not available to ordinary pilot accounts.

Does ORBIT support other tools?

Earlier owner-only integrations include YouTrack; the V6 pilot focuses on per-user GitHub and GitLab connections. Additional integrations are planned, not promised.

Is there a price?

Public pricing has not been announced. ORBIT is currently being evaluated as an invite-only pilot.
